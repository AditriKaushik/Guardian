# नन्हा स्कूल (Nanha School) — बात बडी

छोटे बच्चों के लिए एक Android ऐप, ख़ास उनके लिए जो **अभी बोलना सीख रहे हैं** या
**पहली बार स्कूल (प्री-नर्सरी / नर्सरी / प्रेप)** जा रहे हैं।

सब कुछ **तस्वीर और आवाज़** पर आधारित है, क्योंकि इस उम्र के बच्चे पढ़ नहीं पाते।
बच्चा किसी भी रंग-बिरंगी तस्वीर पर दबाता है, बडी उसका नाम **बोलकर** बताता है, और
बच्चा बोलकर या छूकर सीखता रहता है — यानी मोबाइल एक अच्छा, सुरक्षित साथी बनता है।

## अंदर क्या-क्या है (सिलेबस)

| तस्वीर | पाठ | क्या सिखाता है |
|--------|-----|----------------|
| 🔤 | ABC | अंग्रेज़ी अक्षर — "A for Apple" (अंग्रेज़ी उच्चारण में) |
| अ | अक्षर | हिंदी वर्णमाला — "क से कमल" |
| 🔢 | गिनती | 1–10, तस्वीरों से गिनकर |
| 🎨 | रंग | रंगों के नाम (पूरा कार्ड उसी रंग का हो जाता है) |
| 🔷 | आकार | वृत्त, वर्ग, त्रिकोण, तारा… |
| 🐘 | जानवर | जानवर और उनकी आवाज़ (गाय — मूँ, कुत्ता — भौं भौं) |
| 🍎 | फल-सब्ज़ी | सेब, केला, गाजर, आलू… |
| 🚗 | वाहन | कार, बस, रेलगाड़ी, हवाई जहाज़… |
| ✋ | शरीर | आँख, कान, नाक, हाथ, पैर… |
| 🙏 | अच्छी बातें | नमस्ते, धन्यवाद, ब्रश करना, हाथ धोना |
| 🎵 | कविताएँ | हिंदी और अंग्रेज़ी की मशहूर बाल-कविताएँ (बोलकर सुनाता है) |
| 🎮 | खेल | "सेब कहाँ है?" — सही तस्वीर पर दबाओ, तारे जीतो |
| 💬 | बात करो | बडी से बातचीत — चुटकुले, कहानी, जोड़-घटाना |

## ख़ास बातें

- **भाषा अपने-आप बदलती है** — अंग्रेज़ी अक्षर अंग्रेज़ी उच्चारण में और हिंदी सामग्री
  हिंदी में बोली जाती है (हर शब्द के साथ आवाज़ की भाषा अपने-आप चुनी जाती है)।
- **धीमी, प्यारी आवाज़** जो छोटे बच्चे आसानी से समझ सकें।
- **कोई हार नहीं** — खेल में गलत जवाब पर भी प्यार से "फिर से कोशिश करो" कहता है।
- **पूरी तरह ऑफ़लाइन** — न इंटरनेट, न अकाउंट, न विज्ञापन। बच्चे की कोई बात फ़ोन से
  बाहर नहीं जाती। यह जान-बूझकर बनाया गया है ताकि यह एक **सुरक्षित डायवर्जन** रहे।
- सुरक्षा: "बात करो" में कोई बच्चा दुखी हो या कोई उसे परेशान करे, तो बडी भरोसेमंद
  बड़ों और चाइल्डलाइन **1098** के बारे में बताता है।

## APK कैसे पाएँ

सीधा डाउनलोड लिंक (फ़ोन में खोलें):
https://github.com/AditriKaushik/Guardian/releases/download/baat-buddy-latest/BaatBuddy.apk

या **Actions → Baat Buddy APK** के किसी रन में **Artifacts → BaatBuddy-apk** (zip) डाउनलोड करें।

फ़ोन में इंस्टॉल करते समय "Unknown apps / अज्ञात स्रोत" की अनुमति देनी होगी।
बोलकर बात करने के लिए फ़ोन में Google ऐप (वॉइस टाइपिंग) और हिंदी text-to-speech होना
चाहिए; न हो तो बच्चा लिखकर या तस्वीर छूकर सीख सकता है।

## ख़ुद बनाना

Android Studio में `android/` फ़ोल्डर खोलें, या:

```bash
cd android
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # बात करने वाले हिस्से के टेस्ट
```
